THE PROJECT

쏟아지는 몬스터, 무너지지 않는 프레임

쏟아지는 몬스터를 처치하며 무기와 패시브를 강화하고, 여섯 장애물 구간과 보스를 넘어 최종 보스에 도전하는 3D 서바이벌 액션입니다.

ENGINEERING NOTES

문제에서 구현까지

01

Profiler로 병목을 찾고 단계적으로 최적화

문제

대량의 Enemy에서 개별 Update 호출, 반복 생성·파괴, Animator 갱신, 전체 적을 순회하는 분리 계산 비용이 누적됐습니다.

구현

EnemyManager의 ManagedUpdate로 갱신을 모으고 Enemy·데미지 텍스트·코인·경험치를 풀링했습니다. SmartVAT로 애니메이션을 텍스처로 베이크해 GPU에서 재생하고 동일 Mesh·Material을 인스턴싱합니다. 2m Grid에서 주변 셀의 후보를 최대 32개 검사하고 조건에 맞는 가까운 이웃으로 분리 계산을 제한합니다.

결과

포트폴리오에 기록한 Unity Editor 측정에서 Separation 중앙값 187.07ms → 4.06ms, 프레임 중앙값 219.25ms → 17.33ms로 감소했습니다. VAT 측정은 별도 조건에서 Animator 2.67ms → 0.07ms로 감소했습니다.

02

NavMesh 없이 다층 지형 추적

문제

적이 플레이어와 다른 층에 있거나 계단·단차를 만났을 때 XZ 추적만으로는 지면 높이를 맞출 수 없었습니다.

구현

플레이어를 향한 수평 이동과 Y 보정을 분리했습니다. 기본 Low Raycast로 같은 층 지면을 찾고, 지면을 놓치거나 플레이어가 더 높은 경우 High Raycast 후보에서 목표 높이에 가까운 지면을 선택합니다.

결과

작은 단차는 빠르게, 큰 단차는 수평 이동을 멈추고 천천히 올라가며, 아래층으로는 낙하하도록 상황별 이동을 구현했습니다.

03

일반 적과 보스의 확장 구조

문제

일반 적의 대량 처리와 보스의 개별 복합 패턴은 서로 다른 갱신·생명주기를 필요로 했습니다.

구현

Enemy와 BossEnemy를 별도 베이스 클래스로 두고 IDamageable 피해 인터페이스를 공유합니다. 일반 적은 중앙 갱신과 풀링을 따르고, 보스는 개별 Update·Coroutine·공격 패턴·사망 이벤트를 사용합니다.

결과

공통 피해 처리와 타입별 행동을 분리해 일반 적 6종과 보스 9종의 동작을 확장했습니다.

04

데이터로 구성한 웨이브와 페이즈 흐름

문제

웨이브·장애물 클리어·중간 보스·최종 보스 전환을 팀원이 조정하기 쉽게 구성해야 했습니다.

구현

Theme → Phase → Wave → Enemy ScriptableObject로 일정과 적 구성을 나눴습니다. 스케줄 커스텀 인스펙터에 페이즈 막대, 정상·Nightmare 타임라인, 웨이브 표와 에셋 이동 기능을 제공합니다.

결과

여섯 번의 웨이브 → 맵 클리어 → 보스 반복 뒤 포털로 최종 페이즈에 진입합니다. 제한 시간 초과 시 별도 악몽 타이머와 웨이브를 시작해 후반 압박을 설계했습니다.
